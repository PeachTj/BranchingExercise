# Git branching

## 1. Viewing Branches

Use `git branch` to view your existing branches,\Look for the * which indicates the branch you are currently on.

## 2.Creating Branches

Use `git branch <branch-name>` to make a new branch based upon the current HEAD. lt does not switch you to that branch (the HEAD stays the same.

## 3.Switching Branches

Once you have created a new branch use `git switch <branch-name>` to switch to it.

Use `git switch -c <branch-name>` to create a new branch AND switch to it all in one go.
